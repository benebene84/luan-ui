# Switch

A toggle between on and off. Size is responsive. Inside `FormField`, it inherits `disabled` and `error`.

## Import

```tsx
import { Switch } from "luan-ui";
```

## Usage

<div className="flex items-center gap-4 py-2">
  <Switch size="small" />
  <Switch size="medium" />
  <Switch size="large" />
  <Switch disabled />
</div>

```tsx
<Switch />
<Switch size="small" />
<Switch checked={enabled} onCheckedChange={setEnabled} />
```
