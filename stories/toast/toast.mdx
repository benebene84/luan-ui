# Toast

Custom toasts built on [Sonner](https://sonner.emilkowal.ski/). Mount `Toaster` once, then call `toast()`.

## Import

```tsx
import { Toaster, toast } from "luan-ui";
```

## Usage

Mount the toaster near the root of the app:

```tsx
import { Toaster } from "luan-ui";

export function App() {
  return (
    <>
      <Toaster />
      {/* routes */}
    </>
  );
}
```

Trigger a toast:

```tsx
toast({
  title: "Invite sent",
  description: "We emailed the invitation.",
  button: {
    label: "Close",
    onClick: () => {},
  },
});
```

The action button runs `button.onClick` and then dismisses the toast. `toast()` returns a toast id. Additional Sonner toaster options can be passed through.

`Toast` is the visual component used internally. Prefer `toast()` rather than rendering `Toast` yourself.
