# Progress

A progress bar with an optional percentage label.

## Import

```tsx
import { Progress } from "luan-ui";
```

## Usage

<div className="flex max-w-md flex-col gap-4 py-2">
  <Progress value={50} />
  <Progress value={75} showLabel={false} />
</div>

```tsx
<Progress value={50} />
<Progress value={75} showLabel={false} />
<Progress value={3} max={10} />
```
