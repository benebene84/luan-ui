# Pagination

Page navigation with previous/next controls and numbered items. Extra page items are truncated around the current page.

## Import

```tsx
import {
  Pagination,
  PaginationItem,
  PaginationNext,
  PaginationPrev,
} from "luan-ui";
```

## Usage

```tsx
<Pagination page={page} totalPages={25} onPageChange={setPage}>
  <PaginationPrev aria-label="Previous">
    <ChevronLeftIcon className="h-5 w-5" />
  </PaginationPrev>
  {Array.from({ length: 25 }, (_, index) => (
    <PaginationItem key={index} index={index + 1} />
  ))}
  <PaginationNext aria-label="Next">
    <ChevronRightIcon className="h-5 w-5" />
  </PaginationNext>
</Pagination>
```

If `PaginationItem` has no children, it renders `index`. `PaginationPrev` is disabled on page 1; `PaginationNext` is disabled on the last page.

The root is a `<nav aria-label="Pagination">`. Override the element with `render`.

## Anatomy

```tsx
<Pagination page={1} totalPages={10} onPageChange={…}>
  <PaginationPrev />
  <PaginationItem index={1} />
  <PaginationNext />
</Pagination>
```
