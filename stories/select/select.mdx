# Select

A single-value picker from a predefined list. Inside `FormField`, it inherits `disabled` and `required`. Portaled — apply the theme on `<html>`.

## Import

```tsx
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectLabel,
  SelectSeparator,
  SelectTrigger,
  SelectValue,
} from "luan-ui";
```

## Usage

Pass `items` on the root so Base UI can match values to labels. Each item is typically `{ value, label }`. Use `value: null` for a placeholder option.

```tsx
<Select items={fruitItems}>
  <SelectTrigger className="w-45">
    <SelectValue />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      <SelectLabel>Fruits</SelectLabel>
      <SelectItem value="apple">Apple</SelectItem>
      <SelectItem value="banana">Banana</SelectItem>
    </SelectGroup>
  </SelectContent>
</Select>
```

## Anatomy

```tsx
<Select>

  </SelectTrigger>
```
