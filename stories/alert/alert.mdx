# Alert

An inline message with a title, description, and optional leading icon. `AlertTitle` and `AlertDescription` inherit size from the parent `Alert`.

## Import

```tsx
import { Alert, AlertDescription, AlertTitle } from "luan-ui";
```

## Usage

<div className="flex flex-col gap-3 py-2">
  <Alert variant="primary">
    <Icon render={<CheckCircledIcon />} size="small" />
    <AlertTitle>Saved</AlertTitle>
    <AlertDescription>Your changes were stored.</AlertDescription>
  </Alert>
  <Alert variant="secondary">
    <AlertTitle>Tip</AlertTitle>
    <AlertDescription>You can undo this action.</AlertDescription>
  </Alert>
  <Alert variant="error">
    <AlertTitle>Something went wrong</AlertTitle>
    <AlertDescription>Please try again.</AlertDescription>
  </Alert>
</div>

```tsx
<Alert variant="primary" size="medium">
  <Icon render={<CheckCircledIcon />} size="small" />
  <AlertTitle>Information</AlertTitle>
  <AlertDescription>This is an informational alert.</AlertDescription>
</Alert>
```

`AlertTitle` and `AlertDescription` accept `render` to change the element (for example `<h4>` or `<p>`).

## Anatomy

```tsx
<Alert>
  {/* optional icon */}
  <AlertTitle />
  <AlertDescription />
</Alert>
```
