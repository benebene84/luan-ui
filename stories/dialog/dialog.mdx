# Dialog

A modal dialog with overlay, header, and footer. `DialogContent` includes a close button. Portaled — apply the theme on `<html>`. See [portals and theming](?path=/docs/conventions--docs#portals-and-theming).

## Import

```tsx
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "luan-ui";
```

## Usage

```tsx
<Dialog>
  <DialogTrigger
    render={(props) => (
      <Button {...props} variant="secondary">
        Open dialog
      </Button>
    )}
  />
  <DialogContent className="w-11/12 md:min-w-md">
    <DialogHeader>
      <DialogTitle>Edit profile</DialogTitle>
      <DialogDescription>Make changes and save when you are done.</DialogDescription>
    </DialogHeader>
    {/* body */}
    <DialogFooter>
      <DialogClose
        render={(props) => (
          <Button {...props} variant="secondary">
            Close
          </Button>
        )}
      />
      <Button variant="primary">Save</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

Control open state with `open` and `onOpenChange`. `DialogTrigger` and `DialogClose` accept `render` for composing with `Button`.

## Anatomy

```tsx
<Dialog>
  <DialogTrigger />
  <DialogContent>
    <DialogHeader>
      <DialogTitle />
      <DialogDescription />
    </DialogHeader>
    <DialogFooter>
      <DialogClose />
    </DialogFooter>
  </DialogContent>
</Dialog>
```
