# Textarea

A styled multi-line text field.

## Import

```tsx
import { Textarea } from "luan-ui";
```

## Usage

<div className="flex max-w-md flex-col gap-2 py-2">
  <Label htmlFor="docs-bio">Bio</Label>
  <Textarea id="docs-bio" placeholder="Tell us about yourself" rows={4} />
</div>

```tsx
<Label htmlFor="bio">Bio</Label>
<Textarea id="bio" placeholder="Tell us about yourself" rows={4} />
```

Use `error` for an error border and `disabled` to prevent editing.
