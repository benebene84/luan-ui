# Radio Group

A set of radio buttons where only one value can be selected. Inside `FormField`, it inherits `disabled` and `required`.

## Import

```tsx
import { Label, RadioGroup, RadioGroupItem } from "luan-ui";
```

## Usage

```tsx
<RadioGroup defaultValue="option1">
  <div className="flex items-center gap-2">
    <RadioGroupItem value="option1" id="option1" />
    <Label htmlFor="option1">Option 1</Label>
  </div>
  <div className="flex items-center gap-2">
    <RadioGroupItem value="option2" id="option2" />
    <Label htmlFor="option2">Option 2</Label>
  </div>
</RadioGroup>
```

<div className="py-2">

</div>
