# Checkbox

A checkbox built on Base UI. Size is responsive. Inside `FormField`, it inherits `disabled` and `required`.

## Import

```tsx
import { Checkbox } from "luan-ui";
```

## Usage

<div className="flex items-center gap-2 py-2">
  <Checkbox id="docs-terms" />
  <Label htmlFor="docs-terms">Accept terms</Label>
</div>

```tsx
<div className="flex items-center gap-2">
  <Checkbox id="terms" />
  <Label htmlFor="terms">Accept terms</Label>
</div>
```

Controlled:

```tsx
<Checkbox checked={checked} onCheckedChange={setChecked} />
```

### Inside FormField

<div className="py-2">
  <FormField orientation="horizontal" required>
    <Label htmlFor="docs-checkbox-terms">Agree to terms</Label>
    <Checkbox id="docs-checkbox-terms" />
    <FormHelper>You must accept to continue.</FormHelper>
  </FormField>
</div>
