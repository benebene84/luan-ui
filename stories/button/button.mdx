# Button

A button with visual variants and sizes. Icons are passed as children. Use `render` to turn the button into a link or another element.

## Import

```tsx
import { Button } from "luan-ui";
```

## Usage

<div className="flex flex-wrap items-center gap-2 py-2">
  <Button variant="primary">Primary</Button>
  <Button variant="secondary">Secondary</Button>
  <Button variant="destructive">Delete</Button>
  <Button disabled>Disabled</Button>
</div>

```tsx
<Button variant="primary">Primary</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="destructive">Delete</Button>
```

### With icons

<div className="py-2">
  <Button>
    <Icon render={<ArrowLeftIcon />} size="small" />
    Continue
    <Icon render={<ArrowRightIcon />} size="small" />
  </Button>
</div>

```tsx
<Button>
  <Icon render={<ArrowLeftIcon />} size="small" />
  Continue
  <Icon render={<ArrowRightIcon />} size="small" />
</Button>
```

### As a link

```tsx
<Button render={<a href="/contact" />}>Contact us</Button>
```

<Canvas of={ButtonStories.AsLink} />

### Responsive size

```tsx
<Button size={{ initial: "small", sm: "medium", md: "large" }}>
```
