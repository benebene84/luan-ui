# Slider

A range input with optional min/max labels and value tooltips on each thumb. Pass an array to `defaultValue` for multiple thumbs. Inside `FormField`, it inherits `disabled`.

## Import

```tsx
import { Slider } from "luan-ui";
```

## Usage

```tsx
<Slider min={0} max={100} defaultValue={50} />
<Slider min={0} max={100} defaultValue={[20, 80]} />
<Slider defaultValue={40} showMinMax={false} showTooltipValue={false} />
```
