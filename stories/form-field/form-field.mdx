# Form Field

A layout wrapper that wires a label, control, and helper text together. It provides `disabled`, `required`, and `error` to nested form controls through context.

`FormHelper` shows supporting or error text and inherits those states.

`FormField` requires a `Label` and a control as children. `FormHelper` is optional.

## Import

```tsx
import { FormField, FormHelper, Input, Label } from "luan-ui";
```

## Usage

```tsx
<FormField required error>
  <Label htmlFor="email">Email</Label>
  <Input id="email" type="email" />
  <FormHelper>There was an error on this field.</FormHelper>
</FormField>
```

The label shows a trailing `*`. The input uses the error border. The helper uses `role="alert"` and error color.

Horizontal layout places the control first, then the label and helper in a column — useful for checkboxes:

```tsx
<FormField orientation="horizontal" required>
  <Label htmlFor="terms">Agree to terms</Label>
  <Checkbox id="terms" />
  <FormHelper>You must agree to continue.</FormHelper>
</FormField>
```

## Anatomy

```tsx
<FormField>
  <Label />
  {/* any form control */}
  <FormHelper />
</FormField>
```
