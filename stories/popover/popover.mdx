# Popover

A floating panel anchored to a trigger. Arrow, close button, and placement are configured on `Popover`. Portaled — apply the theme on `<html>`.

## Import

```tsx
import { Popover, PopoverContent, PopoverTrigger } from "luan-ui";
```

## Usage

```tsx
<Popover>
  <PopoverTrigger render={<Button variant="secondary" />}>
    Open popover
  </PopoverTrigger>
  <PopoverContent>
    <div className="flex flex-col gap-2">
      <h3 className="font-medium">Popover title</h3>
      <p>Basic popover content.</p>
    </div>
  </PopoverContent>
</Popover>
```

```tsx
<Popover side="bottom" showArrow={false} showCloseButton={false}>
  <PopoverTrigger render={<Button />}>Info</PopoverTrigger>
  <PopoverContent>No arrow, no close button.</PopoverContent>
</Popover>
```

Also exported: `PopoverClose`, `PopoverAnchor`, `PopoverPortal`.

## Anatomy

```tsx
<Popover>
  <PopoverTrigger />
  <PopoverContent />
</Popover>
```
