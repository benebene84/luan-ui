# Label

A form label. Inside `FormField`, it inherits `required` and shows a trailing asterisk.

## Import

```tsx
import { Label } from "luan-ui";
```

## Usage

<div className="flex max-w-sm flex-col gap-2 py-2">
  <Label htmlFor="docs-label-email" required>
    Email
  </Label>
  <Input id="docs-label-email" type="email" />
</div>

```tsx
<Label htmlFor="email" required>
  Email
</Label>
<Input id="email" type="email" />
```
