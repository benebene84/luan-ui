# Tooltip

A short label shown on hover or focus. Each `Tooltip` includes its own delay provider. Portaled — apply the theme on `<html>`.

## Import

```tsx
import { Tooltip, TooltipContent, TooltipTrigger } from "luan-ui";
```

## Usage

```tsx
<Tooltip>
  <TooltipTrigger render={<Button variant="secondary" />}>
    Hover me
  </TooltipTrigger>
  <TooltipContent>
    <p>Tooltip content</p>
  </TooltipContent>
</Tooltip>
```

<div className="py-2">
  <Tooltip>
    <TooltipTrigger render={<Button variant="secondary" />}>
      Hover me
    </TooltipTrigger>
    <TooltipContent>
      <p>Saves the document</p>
    </TooltipContent>
  </Tooltip>
</div>

`delayDuration` defaults to `600` ms. `sideOffset` defaults to `10`. Set `showArrow={false}` to hide the arrow.

## Anatomy

```tsx
<Tooltip>
  <TooltipTrigger />
  <TooltipContent />
</Tooltip>
```
