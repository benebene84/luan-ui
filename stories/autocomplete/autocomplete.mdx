# Autocomplete

An input that suggests options as you type. Unlike [Combobox](?path=/docs/components-combobox--docs), the value can be free-form text; suggestions are optional. Inside `FormField`, it inherits `disabled` and `required`. Portaled — apply the theme on `<html>`.

## Import

```tsx
import {
  Autocomplete,
  AutocompleteClear,
  AutocompleteCollection,
  AutocompleteContent,
  AutocompleteEmpty,
  AutocompleteGroup,
  AutocompleteGroupLabel,
  AutocompleteInput,
  AutocompleteInputGroup,
  AutocompleteItem,
  AutocompleteList,
  AutocompleteSeparator,
  AutocompleteTrigger,
  useAutocompleteFilteredItems,
} from "luan-ui";
```

## Usage

Use `itemToStringValue` when items are objects so filtering and the input value use a string.

```tsx
<Autocomplete items={tagItems} itemToStringValue={(tag) => tag.value}>
  <AutocompleteInputGroup className="w-60">
    <AutocompleteInput placeholder="Search tags…" />
    <AutocompleteClear />
    <AutocompleteTrigger />
  </AutocompleteInputGroup>
  <AutocompleteContent>
    <AutocompleteEmpty>No tags found.</AutocompleteEmpty>
    <AutocompleteList>
      {(tag) => (
        <AutocompleteItem key={tag.id} value={tag}>
          {tag.value}
        </AutocompleteItem>
      )}
    </AutocompleteList>
  </AutocompleteContent>
</Autocomplete>
```

For grouped lists, use `useAutocompleteFilteredItems` with `AutocompleteGroup` and `AutocompleteCollection`.

## Anatomy

```tsx
<Autocomplete>
  <AutocompleteInputGroup>
    <AutocompleteInput />
    <AutocompleteClear />
    <AutocompleteTrigger />
  </AutocompleteInputGroup>
  <AutocompleteContent>
    <AutocompleteEmpty />
    <AutocompleteList>
      <AutocompleteItem />
    </AutocompleteList>
  </AutocompleteContent>
</Autocomplete>
```
