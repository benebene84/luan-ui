# Icon

A sized wrapper for SVG icons. Pass the icon through `render`.

## Import

```tsx
import { Icon } from "luan-ui";
```

## Usage

<div className="flex items-center gap-4 py-2">
  <Icon render={<StarIcon />} size="small" />
  <Icon render={<StarIcon />} size="medium" />
  <Icon render={<StarIcon />} size="large" />
</div>

```tsx
import { StarIcon } from "@radix-ui/react-icons";
import { Icon } from "luan-ui";

<Icon render={<StarIcon />} size="medium" />
```

Sizes map to `16`, `24`, and `32` pixels. `className` is useful for color (`text-primary`).
