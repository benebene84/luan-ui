# Skeleton

A pulsing placeholder for content that is still loading. Size and shape come from `className`.

## Import

```tsx
import { Skeleton } from "luan-ui";
```

## Usage

<div className="flex flex-col gap-3 py-2">
  <Skeleton className="h-12 w-12 rounded-full" />
  <Skeleton className="h-4 w-[250px]" />
  <Skeleton className="h-4 w-[200px]" />
</div>

```tsx
<Skeleton className="h-4 w-[250px]" />
<Skeleton className="h-12 w-12 rounded-full" />
```
