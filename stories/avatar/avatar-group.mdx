# Avatar Group

Overlaps a row of avatars and reveals a leftover count on hover when there are more than `maxAvatars`.

## Import

```tsx
import { Avatar, AvatarFallback, AvatarGroup, AvatarImage } from "luan-ui";
```

## Usage

```tsx
<AvatarGroup maxAvatars={3}>
  <Avatar>
    <AvatarImage src="https://github.com/benebene84.png" alt="@benebene84" />
    <AvatarFallback>BS</AvatarFallback>
  </Avatar>
  <Avatar>
    <AvatarFallback>U2</AvatarFallback>
  </Avatar>
</AvatarGroup>
```

Hovering the group spreads the avatars and shows `+N` for hidden ones.
