# Avatar

A user image with a fallback when the image is missing or still loading. Default size is `40×40`; override with `className`.

## Import

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "luan-ui";
```

## Usage

```tsx
<Avatar>
  <AvatarImage src="https://github.com/benebene84.png" alt="@benebene84" />
  <AvatarFallback>BS</AvatarFallback>
</Avatar>
```

## Anatomy

```tsx
<Avatar>
  <AvatarImage />
  <AvatarFallback />
</Avatar>
```

See also [Avatar Group](?path=/docs/components-avatargroup--docs).
