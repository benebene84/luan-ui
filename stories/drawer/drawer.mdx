# Drawer

A sliding panel from any side of the viewport. Swipe to dismiss matches the `side` prop (`left`, `right`, `top`, `bottom`; default `"right"`). Portaled — apply the theme on `<html>`.

## Import

```tsx
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "luan-ui";
```

## Usage

```tsx
<Drawer side="right">
  <DrawerTrigger render={(props) => <Button {...props}>Open drawer</Button>} />
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Drawer title</DrawerTitle>
      <DrawerDescription>Description of the drawer content.</DrawerDescription>
    </DrawerHeader>
    <div className="py-4">
      <p>Main content of the drawer.</p>
    </div>
    <DrawerFooter>
      <DrawerClose
        render={(props) => (
          <Button {...props} variant="secondary">
            Cancel
          </Button>
        )}
      />
      <Button>Save changes</Button>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

`DrawerContent` includes a close icon in the corner. Use the story controls to try each `side`.
