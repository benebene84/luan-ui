# Card

A bordered container with optional header, content, and footer. Nested parts inherit `size` from `Card`.

## Import

```tsx
import { Card, CardContent, CardFooter, CardHeader } from "luan-ui";
```

## Usage

```tsx
<Card size="medium">
  <CardHeader>
    <h3 className="font-semibold text-lg">Card title</h3>
  </CardHeader>
  <CardContent>
    <p>Main content goes here.</p>
  </CardContent>
  <CardFooter>
    <Button variant="secondary">Read more</Button>
  </CardFooter>
</Card>
```

`CardHeader`, `CardContent`, and `CardFooter` must be used inside `Card`. Use `render` on `Card` to change the element (for example `<article>`).

## Anatomy

```tsx
<Card>
  <CardHeader />
  <CardContent />
  <CardFooter />
</Card>
```
